## 带语言标注的代码块

在第二小节里，看一个简单的例子：

```python
def hello(name: str) -> str:
    return f"你好，{name}"

print(hello("世界"))
```

不同方案之间存在一些差异，可以用表格对比：

| 方案 | 优点 | 需要注意 |
| --- | --- | --- |
| 静态生成 | 速度快、安全 | 需构建步骤 |
| 动态渲染 | 灵活 | 需要服务端 |
